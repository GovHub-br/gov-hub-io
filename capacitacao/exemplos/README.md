# Exemplos

Material de apoio referenciado pelas páginas da trilha: conjuntos de dados de exemplo, arquivos de
tema, wireframes e exportações de painéis usadas nos tutoriais e no desafio.

Sugestão de organização:

```
exemplos/
├── dados/        conjuntos de exemplo usados no tutorial
├── temas/        arquivos JSON de tema do Power BI
└── wireframes/   rascunhos de layout antes da construção
```

Nada aqui é conteúdo da trilha — as páginas ficam em `docs/`.
