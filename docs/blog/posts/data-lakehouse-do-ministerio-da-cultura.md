<span class="ghx-eyebrow">MinC · UnB · Lab Livre</span>
<h2><span class="ghx-light">Uma plataforma corporativa de dados</span> para as políticas culturais</h2>
<p class="ghx-lead">O Data Lakehouse é uma plataforma tecnológica criada para modernizar o armazenamento e a análise de informações do setor cultural no Ministério da Cultura (MinC). Seu objetivo é reunir as bases de dados das políticas públicas culturais em uma camada única, interoperável, governada e auditável.</p>
<p class="ghx-lead">A solução é desenvolvida pelo MinC em parceria com o Laboratório Livre (Lab Livre) da Universidade de Brasília (UnB), visando apoiar a formulação, o monitoramento e a avaliação das políticas do Ministério.</p>

<span class="ghx-pill">Auditável</span>

<span class="ghx-eyebrow">O problema</span>
<h2><span class="ghx-light">Dados</span> fragmentados</h2>
<p>O projeto visa solucionar o problema da fragmentação dos dados das políticas culturais. Hoje, os dados de diversas políticas do MinC ficam em <strong>sistemas distintos, com diferentes modelos de dados, regras e formas de acesso</strong>.</p>
<p>A adoção de uma arquitetura de Data Lakehouse permite a criação de uma <strong>infraestrutura unificada</strong>.</p>
</div>
<div>
<span class="ghx-eyebrow ghx-fontes-l">O que a infraestrutura unificada facilita</span>
<div class="ghx-fontes">
<div class="ghx-fonte"><div class="ghx-t">Cruzamento de bases</div></div>
<div class="ghx-fonte"><div class="ghx-t">Cálculo de indicadores consistentes</div></div>
<div class="ghx-fonte"><div class="ghx-t">Auditoria de resultados</div></div>
</div>
<div class="ghx-pergunta">
<div class="ghx-t">Menos retrabalho</div>
<p>Ao centralizar os dados em um único local, o projeto reduz retrabalhos e divergências operacionais.</p>
</div>
</div>
