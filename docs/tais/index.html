graphrag-tais arquitetura

Mapa de arquitetura · Gov Hub

Um assistente que entende o dado de cada ministério

O graphrag-tais é um GraphRAG de metadados para text-to-SQL: ele aprende o que cada tabela significa e como as tabelas se ligam, escolhe o pedaço do catálogo de que a pergunta precisa e deixa um LLM escrever o SQL, que roda em modo somente leitura. O motor é um só; o catálogo, os dados e as perguntas mudam de ministério para ministério. Escolha um para ver a arquitetura no contexto dele.
