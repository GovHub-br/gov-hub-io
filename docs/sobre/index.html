O que é o Gov Hub?

O Gov Hub é uma plataforma de software livre desenvolvida para transformar dados brutos em informações estratégicas, apoiando gestores públicos a tomar decisões baseadas em dados.

Integração automatizada e segura dos dados
Governança de dados e transparência
Visualizações personalizáveis e insights estratégicos
Quem somos

Por que fazemos o que fazemos

Somos um projeto do Lab Livre, Laboratório de Competência em Software Livre da Universidade de Brasília (UnB). O Lab Livre é interdisciplinar e atua com projetos de inovação, participação e transparência a partir de tecnologias abertas.

O Gov Hub existe para fortalecer a capacidade do Estado de coordenar, gerir e monitorar políticas públicas a partir do uso integrado de dados, aprimorando a transparência e a tomada de decisão.

E porque acreditamos que conhecimento público deve ser aberto, todo o código do Gov Hub é livre, auditável e colaborativo, qualquer órgão pode usar, adaptar e contribuir para o seu aprimoramento.

Nossa filosofia
  • Ciência aplicada.
  • Código compartilhado.
  • Impacto multiplicado.

Nosso horizonte

Queremos um mundo onde políticas e serviços públicos funcionem de forma mais justa, efetiva e transparente e onde cidadãos tenham capacidade de compreender e influenciar as decisões do governo.
Nossa história

Nossa história

A realidade da gestão de dados no governo federal é crítica, existem muitas informações, mas elas raramente se conectam por estarem espalhadas em diferentes sistemas. Cada órgão público usa seus próprios sistemas de orçamento, contratos e dados pessoais; e quando é preciso reunir essas informações para tomar decisões, o trabalho leva horas para juntar e ler planilhas manualmente. O problema não é a falta de dados e sim a falta de integração entre eles.

Foi para resolver isso que em 2024 o Ipea (Instituto de Pesquisa Econômica Aplicada) procurou o Lab Livre (Laboratório de Competência em Software Livre da Universidade de Brasília) e dessa parceria nasceu o Gov Hub, uma iniciativa pensada para dar ao Estado a capacidade de enxergar seus próprios dados de forma integrada, confiável e acessível.

A experiência acumulada nessa parceria virou conhecimento compartilhado: deu origem ao livro Gov Hub: um guia prático para integração e qualificação de dados públicos, que documenta a metodologia desenvolvida e hoje serve de base para os projetos implementados em outros órgãos.

Propósito

Por que existe?

Para implementar a interoperabilidade no setor público, unindo dados fragmentados e garantindo informações confiáveis para decisões e transparência.

O que o Gov Hub faz

Uma camada de integração e qualificação de dados

O Gov Hub atua como uma camada de integração e qualificação de dados, permitindo que informações dispersas em diferentes sistemas governamentais sejam:

  • Integradas
  • Padronizadas
  • Qualificadas
  • Transformadas em insumos estratégicos para gestão e políticas públicas

Potencializamos informações de sistemas como TransfereGov, Siape, Siafi, ComprasGov e Siorg para gerar diagnósticos estratégicos, indicadores confiáveis e decisões baseadas em evidências.

  • TransfereGov

  • Transparência pública e cultura de dados abertos
  • Indicadores confiáveis para acompanhamento e monitoramento

  • Exploração de inteligência artificial para gerar insights
  • Gestão orientada a dados em todos os níveis
Diferenciais

Quais são nossos diferenciais?

Tudo em um

Em vez de acessar e cruzar manualmente dados de diferentes sistemas estruturantes, o Gov Hub reúne tudo em uma única plataforma, oferecendo informações integradas, qualificadas e prontas para uso na gestão pública.

Software livre e confiável

O Gov Hub é 100% open source, garantindo autonomia, transparência e colaboração entre órgãos públicos. Sua stack tecnológica é padrão e já utilizada amplamente pelo governo.

Arquitetura modular

A solução é desenhada para ser flexível: integrações feitas com sistemas estruturantes podem ser reutilizadas em outros órgãos, além de permitir a conexão com sistemas próprios do órgão.

Medallion e governança de dados

A arquitetura em camadas (bronze, prata e ouro) garante qualidade progressiva dos dados, enquanto a governança assegura rastreabilidade, confiabilidade e uso estratégico das informações.

Respostas inteligentes com IA

Com o uso de RAG (Retrieval Augmented Generation), o Gov Hub permite responder a perguntas negociais diretamente, sem depender apenas de dashboards, agilizando análises e decisões.

Tecnologia

Com o que foi desenvolvido?

O projeto adota um stack tecnológico baseado em soluções open-source, incluindo Apache Airflow para orquestração de pipelines de dados, DBT para transformação e modelagem de informações, Apache Superset para visualização e exploração, PostgreSQL como banco de dados relacional e Docker para containerização e implantação.

A escolha dessas tecnologias permite maior flexibilidade, escalabilidade e integração com diferentes sistemas governamentais.

  • Orquestração de pipelines de dadosApache Airflow
  • Transformação e modelagem de dadosData Build Tool
  • Visualização e exploração de dadosApache Superset
  • Banco de dados relacionalPostgreSQL
  • Containerização e implantação de aplicaçõesDocker
  • Retrieval Augmented GenerationEm breveHaystack
  • Banco de dados vetorialEm breveQdrant
