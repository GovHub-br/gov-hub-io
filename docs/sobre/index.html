Sobre o Gov Hub

O que é o Gov Hub?

O Gov Hub é uma plataforma livre que qualifica e integra dados dos sistemas estruturantes, transformando-os em informações estratégicas para gestão pública baseada em evidências.

Por que existe?

Para implementar a interoperabilidade no setor público, unindo dados fragmentados e garantindo informações confiáveis para decisões e transparência.

Quais são nossos diferenciais?

Tudo em um

Em vez de acessar e cruzar manualmente dados de diferentes sistemas estruturantes, o Gov Hub reúne tudo em uma única plataforma, oferecendo informações integradas, qualificadas e prontas para uso na gestão pública.

Software livre e confiável

O Gov Hub é 100% open source, garantindo autonomia, transparência e colaboração entre órgãos públicos. Sua stack tecnológica é padrão e já utilizada amplamente pelo governo.

Arquitetura modular

A solução é desenhada para ser flexível: integrações feitas com sistemas estruturantes podem ser reutilizadas em outros órgãos, além de permitir a conexão com sistemas próprios do órgão.

Medallion e governança de dados

A arquitetura em camadas (bronze, prata e ouro) garante qualidade progressiva dos dados, enquanto a governança assegura rastreabilidade, confiabilidade e uso estratégico das informações.

Respostas inteligentes com IA

Com o uso de RAG (Retrieval Augmented Generation), o Gov Hub permite responder a perguntas negociais diretamente, sem depender apenas de dashboards, agilizando análises e decisões.

Com que foi desenvolvido?

O projeto adota um stack tecnológico baseado em soluções open-source, incluindo Apache Airflow para orquestração de pipelines de dados, DBT para transformação e modelagem de informações, Apache Superset para visualização e exploração, PostgreSQL como banco de dados relacional e Docker para containerização e implantação. A escolha dessas tecnologias permite maior flexibilidade, escalabilidade e integração com diferentes sistemas governamentais.

Como utilizar?

O Gov Hub pode ser hospedado na infraestrutura do próprio órgão, garantindo autonomia e segurança. Os painéis são oferecidos por padrão no Superset, acessível via navegador, mas é possível conectar a base qualificada em outras ferramentas de visualização. Parte dos dados utilizados depende de acesso autorizado pelos órgãos responsáveis. A configuração é responsabilidade do órgão, com apoio disponível por meio de parceiros.

Missão

Promover a interoperabilidade de dados do Estado brasileiro, traduzindo a complexidade tecnológica em decisões baseadas em evidências, baseada em dados. Nosso propósito é fortalecer a capacidade governamental de gerir políticas públicas e converter a informação (dados) em transparência acionável para a sociedade.

Visão

Ser a principal infraestrutura pública de dados em software livre da América Latina, referência em governança, usabilidade e impacto democrático.

Valores do Gov Hub

Soberania Tecnológica e Código Aberto

Adotamos o software livre não apenas como ferramenta, mas como base inegociável para garantir a confiança, a auditabilidade e a independência técnica do Estado.

Transparência Ativa

Entendemos a abertura de dados como o princípio estruturante do projeto, essencial para o fortalecimento da democracia e a legitimação das políticas públicas.

Rigor Metodológico

Atuamos para substituir o empirismo pela inteligência de dados, garantindo que o planejamento e o monitoramento governamental sejam estritamente baseados em evidências.

Autonomia e Transferência de Tecnologia

Fomentamos o conhecimento aberto com o objetivo prático de fortalecer as capacidades estatais, assegurando que os órgãos parceiros não criem dependência, mas ganhem autonomia técnica.

Acessibilidade e Escuta Ativa

Compreendemos que dados só geram valor se forem entendidos. Mantemos uma postura empática e utilizamos linguagem simples para traduzir a complexidade para gestores, servidores e cidadãos.

Sob que licença está o código?

O Gov Hub é totalmente open source: código livre, transparente e auditável. Isso garante autonomia aos órgãos públicos, fomenta colaboração e evita dependência de fornecedores proprietários.
